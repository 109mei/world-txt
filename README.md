# WORLD.txt — 世界再定義（試作）

> 世界は、文章でできている。

世界を定義している文章を、消して、書き換えて、書き足して、人類文明を存続させるゲーム。スマホ縦画面のブラウザで遊ぶ。

- 「人間は毎日食事を必要とする。」を「人間は数日に一度食事を必要とする。」に書き換えると、食料危機は去る。だが農業が縮み、作物の研究が止まり、数年後に新種の作物病原体が来る。
- 「人間は空を飛べる。」と書き足すと、人類は空を飛ぶ。空の交通事故が増え、国境は空から越えられるようになる。
- 「二酸化炭素は熱を閉じ込める。」を消すと、地球は涼しくなる。そして氷期が来る。

選択肢も予測もない。書いた文章を世界がどう読み取り、何が起きるかは、時間を進めて確かめる。想定外の変化には、それがどの一文から来たか（← 書いた文章）と、現実の「なぜ？」が添えられる。

- どんな文でも受け取る：その行の新しい意味・新しい概念（1文にいくつでも）・別の行の書き換え・すでにある意味・意味のない文（「『ポポポ』は、世界に意味が伝わらない言葉」のように理由つき。世界は何も変わらない）のどれかになる。英語でも書ける
- 人工知能・半導体・反物質・ブラックホール・ベーシックインカムのような専門の言葉も、「人は服を着ない」「人は人を食べる」のような無茶な決まりも読み取り、現実の仕組みに沿った結果になる。辞書にない言葉も、語尾から種類を推し量る（「顔認証カメラ」は機械、「肺炎」は病気）
- 世界容量は WORLD.txt の文字数。短く言い換えれば、意味を変えずに字数を減らせる
- ステージは7つ：食料危機・感染症・気候危機・世界大戦・資源枯渇・極小世界（はじめから世界容量をはみ出していて、何を残し何を捨てるかを選ぶ）・くり返す十年（10年ごとに0年目へ巻き戻る世界。書いた文章だけが残る。破局の原因を突き止めて断ち、11年目へ抜け出す）
- ∞ 無限の世界：文明が滅ぶまで続き、何年続いたかを競う。隕石・未知の病・破局噴火・世界大戦などの危機の知らせが届き、数年後に世界を襲う。襲う年までに世界の定義を書き換えれば防げることがある。長く続いた上位10件は、称号つきで記録簿（この端末のランキング）に残る。「今日の世界」は日付で決まり、同じ日なら誰でも同じ世界
- 宇宙・地球・重力・太陽・人類を消す、原子をまとめる力を消す、時間を止める、宇宙人を呼ぶ、星々へ移り住む……。特別な結末が41ある（「無」「ほどけた物質」「呑まれた星」「永遠の一瞬」「星々の友」「楽園」、滅び方の名前「核の冬」「紙くずの星」「心の尽きた星」など）。時間を操る文は、その年のうちに結末になる
- 実績は59。見つけた読み取り・想定外の変化・出来事・危機・結末・実績は「観測記録」に集まる（全1074）
- 開ける世界は1つだけ。別の世界を開くときは、遊んでいる世界を放棄してよいかを確かめる
- 終わった世界は、名前つきのカードと人口・文明の曲線になり、画像で共有できる

## 遊ぶ

```bash
npm install
npm run dev
```

http://localhost:5174/world-txt/ を開く（スマホ縦画面の幅がおすすめ）。

## 開発

```bash
npm test          # Vitest
npm run e2e       # Playwright（390×844）
npm run screens   # スクリーンショットを docs/screens/ に保存
npm run sim -- climate all 30   # 作戦ごとのクリア率（food / plague / climate / war / energy / tiny / loop）
npm run sim -- endless all 30   # 無限の世界で、ボットごとに文明が何年続いたか
npm run worlds    # 宇宙・重力・宇宙人・不死などの書き換えを遊んで、どの結末になるかを数える
npm run fuzz      # いろいろな単語をいろいろな位置に入れた約2万文で、読み取りを総当たりする
npm run build     # 公開用ビルド（dist/）
```

仕様は [docs/SPEC.md](docs/SPEC.md)、開発の決まりは [CLAUDE.md](CLAUDE.md)。
