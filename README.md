# ラプラスの庭（WORLD.txt）

> 世界は、文章でできている。そして、書かれたとおりに動く。

世界を定義している文章を、消して、書き換えて、書き足して、人類文明を存続させるゲーム。スマホ縦画面のブラウザで遊ぶ。

- 「人間は毎日食事を必要とする。」を「人間は数日に一度食事を必要とする。」に書き換えると、食料はしばらく足りる。だが農業が縮み、作物の研究が止まり、数年後に新種の作物病原体が来る。
- 「人間は空を飛べる。」と書き足すと、人類は空を飛ぶ。空の交通事故が増え、国境は空から越えられるようになる。
- 「二酸化炭素は熱を閉じ込める。」を消すと、地球は涼しくなる。そして氷期が来る。

選択肢も予測もない。書いた文章を世界がどう読み取り、何が起きるかは、時間を進めて確かめる。想定外の変化には、それがどの一文から来たかと、現実の「なぜ？」が添えられる。

## ラプラスの決まり

遊んでいる間、世界はさいころを振らない。世界の初期条件と出来事の起きる時期は、世界番号（#0001〜#9999）から決まる式だけで決まる。同じ世界番号・同じ書き方なら、誰が遊んでも同じ世界になる。負けた世界は、書いた手の並び（棋譜）から作り直して、1年ずつ見返したり、分かれ道の年からやり直したりできる。

## 遊び方の芯

- **兆しを読んで見立てる**：同じ食料危機でも、世界番号ごとに原因の型（水が足りない・届かない・病害）が違う。はじめの2年のニュースに型の兆しが出る。型に合った仕組みを書き足さないと、数年後に同じ壁がくり返し、大崩れが来る
- **一手では救えない**：どのステージも、一手だけの書き換えでは救えない。型に合った仕組みと、副作用やあとから来る危機への手を組み合わせて（5〜7手）、はじめて解ける。何もしない・でたらめでは救えない
- **どんな文でも受け取る**：その行の新しい意味・新しい概念（1文にいくつでも）・別の行の書き換え・すでにある意味・意味のない文（理由つき。世界は何も変わらない）のどれかになる。英語でも書ける。人工知能・反物質・ベーシックインカムのような専門の言葉も、「人は服を着ない」のような無茶な決まりも読み取る
- **書き方で効き方が変わる**：言い切りの強さ（必ず／かもしれない）、読まれ方（人の性質として・制度として・条件つきで）、効き始めるまでの年（建てる・育てるものほど遅い）、世界の慣れ（長く続くと効きが落ちる）
- **人々の心と社会の学問**：信頼・先行きの不安と買いだめ・慣れと損の重さ・用心の波・考え方の広がり・締め出し・ただ乗り・転換点の前ぶれなど、学問の仕組み25が世界の中で動いている。1回のプレイで新しく覚えるのは1つ。紹介する前は弱く動き、体験してから名前と画面が開く

## 世界

- **序章「ひと区画の庭」**：5行だけの小さな世界で、書き換える・書き足す・消すを1年に1つずつ試す
- **ステージ**：食料危機・感染症・気候危機・世界大戦・資源枯渇・極小世界（はじめから使える文字数をはみ出していて、何を残すかを選ぶ）・くり返す十年（10年ごとに0年目へ巻き戻る。破局の連鎖を断って11年目へ抜け出す）
- **無限の世界**：文明が滅ぶまで続き、何年続いたかを競う。隕石・未知の病・破局噴火などの危機の知らせが届き、数年後に襲う。「今日の世界」は日付で決まる。長く続いた上位10件は称号つきで記録簿（この端末の中）に残る
- **特別な結末41**：宇宙・重力・太陽・時間・原子の力を書き換えると、「無」「ほどけた物質」「永遠の一瞬」「星々の友」「楽園」、滅び方の名前「核の冬」「紙くずの星」など

## 画面

- **世界の情景**：町の灯り・遠近法の畑と鍬をふるう人・森・川・海・煙・霧・戦火と、書き換えたことのすべてを、写本の挿し絵のように描く（二つの太陽・宇宙人の船・恐竜・独裁者の像……）。書き換えから来たものは青いインク。畑・川と水・病院・工場・港などに施設の名前と、気がかりな状態の言葉を添える
- **世界の寿命と4つの柱**：いちばん近い終わりの線まで「あと約◯年」。命・糧・社会・大地の4つの柱に、いちばん低い項目と状態の言葉。**起きかけていること**（兆し）のカードを押すと、情景の同じ場所が光る
- **計算の演出と因果の連鎖**：1年進めると、世界が決まりどおりに計算される短い演出のあと、書いた一文から、直接・つながって・想定外の変化へ光の線が伸びる
- **結末**：世界の最後の姿、敗因の振り返り（崩れた年 → 原因の出来事 → 分かれ道 → 書いた一文）、3つの印（救った・少ない手で・早く見抜いた）、人口と文明の曲線、再生、分かれ道からやり直す、名前つきのカードと画像での共有
- **筆の位**：世界を救うたびに上がり、書き換えられる行・書き足せる行の数・書ける概念の重さが広がる。3つの印をそろえると**改稿者の試練**（原因が2つ重なる・兆しが遅れる・書き換えが少ない）
- **ノート**：図鑑（世界の決まり25・現実のカード77・特別な結末・世界の名前）、実績69（発見・腕前・物語・遊び方）、観測記録1239、現実の数字の出典
- **暗い画面と明るい画面**：黒と銀／紙と墨。最初は端末の設定に合わせる。動くのは何か起きたときだけ

## 遊ぶ

```bash
npm install
```

```bash
npm run dev
```

http://localhost:5174/world-txt/ を開く（スマホ縦画面の幅がおすすめ）。公開版：https://109mei.github.io/world-txt/

## 開発

```bash
npm test          # Vitest
npm run e2e       # Playwright（390×844）
npm run screens   # スクリーンショットを docs/screens/ に保存（暗い画面と、L で始まる明るい画面）
npm run sim -- food all 30      # 作戦ごとのクリア率（prologue / food / plague / climate / war / energy / tiny / loop）
npm run sim -- endless all 30   # 無限の世界で、ボットごとに文明が何年続いたか
npm run sim -- intro 30         # 紹介前の決まりが負けの主な原因になった割合
npx tsx scripts/bots.ts read all 30   # 兆しを読んで見立てるボットのクリア率と、型と作戦の表
npx tsx scripts/par.ts all 30         # 型ごとの作り手の解が、どの世界番号で通るか
npm run worlds    # 宇宙・重力・宇宙人・不死などの書き換えを遊んで、どの結末になるかを数える
npm run fuzz      # 約2万文の読み取りの総当たりと、棋譜から作り直した世界の一致
npm run ranks     # どのステージも、はじめて遊べる筆の位で作戦が止まらず、クリアできる作戦があるか
npx playwright test --config playwright.perf.config.ts   # 演出中の1秒あたりのコマ数（CPU を4倍遅くして）
npm run build     # 公開用ビルド（dist/）
```

仕様は [docs/SPEC.md](docs/SPEC.md)、開発の決まりは [CLAUDE.md](CLAUDE.md)、画面の言葉は [docs/TERMS.md](docs/TERMS.md)、現実の数字の出典は [docs/SOURCES.md](docs/SOURCES.md)。
