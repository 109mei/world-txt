# 世界再定義（仮） ― 世界を書き換えて、人類を救え ―

（ユーザーから受け取った企画書。試作で変えた点は末尾の「試作で変えたこと」を参照）

## 1. ゲーム概要

プレイヤーが操作できるのは、「世界を定義している文章」だけである。

世界には最初から、「人間は酸素を必要とする」「植物は光を受けて成長する」「火は可燃物を燃やす」「病原体は生物に感染する」「国家は領土を所有する」といった数百個の「世界定義」が存在する。

プレイヤーは限られた編集能力を使って、追加・削除・置換・条件追加・例外設定を行う。文章を書き換えると、世界そのものが変化する。

目的はステージごとに明確に設定される（例：「100年間、人類を絶滅させるな」「30年以内に世界人口を回復させろ」「100年間、大規模戦争を発生させるな」「文明を宇宙時代まで発展させろ」「極端に小さな世界容量で1000年間文明を維持せよ」）。

プレイヤーは「正しい文章」を探すのではない。限られた世界容量の中で、何を残し、何を削り、何を書き換えるかを考えるゲームである。

## 2. ジャンル

テキストベース世界シミュレーション＋パズル＋ローグライト＋文明シミュレーション＋ビルド構築。一般的なカードゲームのカードに相当するものが、本作では「概念」と「世界法則」になる。

## 3. 最大の特徴

普通のゲームでは「世界のルールに従って攻略する」。本作では「世界のルールそのものを攻略する」。

例えば食料不足が発生した場合、普通なら農場を増やす。本作では「人間は毎日食事を必要とする」を「人間は数日に一度だけ食事を必要とする」と変更できる。すると食料問題は改善する。しかし、食料需要低下 → 農業縮小 → 農業従事者減少 → 農業研究停滞 → 技術力低下 → 別の食料危機、といった連鎖が発生する。

「悪いものを消せば勝てるゲーム」にはしない。

## 4〜6. 世界容量

タイトルやキャッチコピーでは「1000文字で世界を救え」のような表現を使ってもよいが、実際のシステムでは単純な文字数制限にはせず「世界容量」を採用する。

すべての世界法則には維持コストが存在する。単純な法則ほど軽く、複雑な法則ほど重い（例：「人間は水を必要とする」は軽い、「人間は満月の日のみ水を必要とせず、それ以外の日には通常の半分の水を必要とする」は重い）。内部では数値を持つが、プレイヤーには ◆余裕／安定／圧迫／過密／限界／崩壊寸前 という状態で表示する。

世界そのものは物質・生命・時間・社会・文明を「定義情報」として維持しているが、何らかの異常により、世界を維持できる情報量が減少している。そのためプレイヤーは「世界に何を残すべきなのか」を決めなければならない。

## 7. 基本ゲームループ

世界を確認 → 重大問題を発見 → 原因を調査 → 世界法則を書き換える → 影響予測を見る → 時間を進める → 直接的な結果 → 間接的な結果 → 想定外の結果 → 再び世界を書き換える。

## 8〜14. 表示の考え方

- プレイヤーは大量の数字を見るのではなく、「世界が今どういう状態なのか」を読む（例：YEAR 37／♥人類 安定 →／🍞食料 不足気味 ↘／⚡エネルギー 深刻 ⇊／◆世界容量 圧迫 ↘）
- 「100/100」「78%」「攻撃力64」のような数値をゲームの中心にしない。アイコン＋状態語＋メーター＋変化方向＋短い文章で伝える
- 状態ランクは項目ごとに言葉を変える（食料：豊富→十分→安定→不足気味→不足→深刻→崩壊、世界情勢：平和→安定→警戒→緊張→危険→開戦寸前→戦争）
- 変化方向：⇈急速改善 ↗改善 →安定 ↘悪化 ⇊急速悪化（「不足 ↗」と「安定 ⇊」の違いを判断材料にする）
- 重要項目にはメーター（余裕 ━━━━╸━━ 限界）
- アイコンは飾りではなく「世界共通言語」（♥人間・健康 ◉人口 🍞食料 💧水 ☁大気 ☀気候・太陽 🌿自然・生態系 ⚡電力・エネルギー ⛏資源 ⚙工業 ⚗科学 ✚医療 ⌂住居 ⚖社会・格差 ☮平和 ⚔戦争 ✈航空 ⚓海運 ▣鉄道 ▰道路 ★文明 ⌛時間 ◆世界容量 !警告 ?未知 ☢世界異常 ∞循環・永続）
- アイコン同士の関係で因果を表す（🍞食料 → ♥人類 → ⚖社会 → ☮平和、🍞食料 ├💧水 ├🌿農業 ├⚡エネルギー └✈物流）

## 15〜17. 編集と予測

例：「植物は水・光・二酸化炭素を利用して成長する。」→「植物は光だけで成長できる。」。予想される影響（💧水不足 大幅改善 ⇈、🍞食料 改善 ↗、🌿生態系 影響あり ?）を表示し、厳密な未来は表示しない。「?」を重要な要素として使い、安全な変更か、未知の大きな変更かを判断させる。

時間を進めると、直接の結果（💧水不足 深刻→安定 ⇈）に続いて「! 想定外の変化：植物が異常増殖しています。都市部にも植物が侵入し、道路・住宅・送電設備への被害が拡大しています」のように結果を提示する。

## 18〜20. 世界ニュース・交通・タグ

世界の変化は短いニュースでも表示する（WORLD NEWS「植物による道路封鎖が世界各地で発生」、SCIENCE「研究者、新たな植物成長現象について説明できず」、ECONOMY「農業関連企業の倒産が相次ぐ」、TRANSPORT「主要国際空港で欠航が増加」、SOCIETY「植物を神聖視する新宗教が急拡大」）。

「人間は自力で飛行できる」を追加すると、✈航空産業 需要急減 ⇊、空港 不要化、⛽石油需要 減少、☀観光 急成長、⚖国境管理 混乱、という連鎖が発生する。

世界全体には特徴を表すタグ（🌿緑化世界 ☮長期平和 ⚡電力不足 ♥長寿社会 ✈超移動社会 ⚖格差社会）が付く。

## 21〜25. 削除・置換・条件・例外・新規概念

- 削除：「人間は老化する」を削除すると、寿命 ⇈、人口 急増、住居 不足、世代交代 停滞、食料 悪化
- 置換：「人間は酸素を必要とする」→「人間は二酸化炭素を必要とする」
- 条件追加：「火は木を燃やす」→「500℃以上の火だけが木を燃やす」（森林火災は減るが、料理・暖房・産業・発電にも影響）
- 例外追加：「重力は物体を地面方向へ引く。ただし人間には作用しない。」
- 新規概念作成：永久電池「外部エネルギーを必要とせず電力を生成する。」非常に強力だが世界容量を大きく消費する

## 26〜28. 万能設定対策・世界整合性・世界異常

「人間は永遠に健康で幸福に生きる。」と書けば終わるゲームにはしない。無茶な設定ほど既存法則との矛盾が生じ、世界整合性（正常／安定／揺らぎ／不安定／危険／崩壊寸前）が下がる。悪化すると世界異常（因果逆転・重複人物・時間停止区域・存在消失・生物融合・物質生成エラー・過去改変・意味消失）が発生する。プレイヤーはあえて世界異常を利用することもできる。

## 29〜31. 主要項目・数字・詳細分析

主要な状態は人類・文明・環境・社会・世界の5カテゴリ程度にまとめ、画面では具体的な項目（♥🍞💧🌿⚡⚗☮✈）で見せる。人口や年数など意味そのものが重要な数字は表示してよい（YEAR 82／人口 約41億人／文明存続 残り18年）。希望するプレイヤーには詳細分析モード（人口推移・資源量・出生率・死亡率・物流量・エネルギー需給）を用意するが、通常プレイでは必要なくてもクリアできる。

## 32〜35. クリア条件・失敗条件・キャンペーン

ステージ開始時に目的を明示する（MISSION「100年間、人類文明を維持してください。」CLEAR条件：♥人類が存続、★文明が維持、☢世界が崩壊していない、⌛100年到達）。失敗条件：♥人類「絶滅」、☢世界整合性「崩壊」、◆世界容量「限界突破」など。

キャンペーン：STAGE 1 食料危機（30年間、人類を維持）／2 感染症（文明崩壊を防ぐ）／3 資源枯渇／4 世界大戦／5 気候危機／6 人口爆発／7 AI文明（「人間とは何か」まで変更できる）／8 世界容量縮小／9 極小世界。最終ステージ「極限まで簡略化された世界で、人類文明を1000年間維持せよ。」（海・動物・国家・貨幣・芸術・宗教・スポーツ・戦争・病気・老化・睡眠・家族・季節から何を捨てるか選ぶ）。

## 36〜39. ローグライト・概念収集・禁止概念・コンボ

キャンペーン後にローグライトモード（世界状態・問題・利用可能概念・世界容量・禁止概念・目標が毎回変化）。クリアで概念（光合成・核融合・量子・共生・人工生命・集合意識・時間・記憶・夢・重力）を解放。世界ごとに存在しない概念（⚡電気なし 💰貨幣なし ☠死なし ✈飛行なし）。世界法則同士のシナジー（♥人間は光合成できる＋🌿植物は少量の水で育つ＋☀太陽光が強い → 「光合成文明」成立、♥人間は冬眠可能＋☀冬が10年間続く＋☀夏が1年間続く → 「11年周期文明」成立）。

## 40. 世界史ログ

プレイヤーの行動はすべて歴史として保存される（YEAR 18 🌿植物の法則変更／YEAR 19 🍞世界的食料危機が終息／YEAR 22 !植物異常増殖／YEAR 27 🌿森林が南米大陸の大部分を覆う／YEAR 31 ⚖ブラジル政府崩壊／YEAR 32 🌿「植物管理国家」が成立）。

## 41〜44. 画面と編集UI

スマートフォン縦画面を基本とする。メイン画面は WORLD — YEAR 37／「人類文明は現在、不安定です。」／各項目／◆世界容量メーター／!重大な変化／［世界］［定義］［編集］［歴史］［時間進行］。定義画面は検索と概念ごとの一覧、関連概念。編集UIは最初から完全自由入力にはせず、主語＋条件＋性質＋対象の構造化編集。ゲーム後半で FREE EDIT を解放し、システムが解析（対象・条件・効果・負荷）して内部の構造化データに変換する。

## 45〜46. AI・LLM の利用と因果システム

LLM に世界シミュレーションそのものを任せない。数値・状態・因果・ルール・イベントは決定論的または半決定論的に管理し、AI は自由文章の解析・ニュース文章生成・世界史生成・NPC コメント・結果説明に使う。一つの変更から、直接結果 → 間接結果 → 社会的結果 → 長期結果 → 想定外結果まで発生させる（「人間は老化しない」→ 寿命改善 → 人口増加 → 住宅不足 → 格差拡大 → 社会不安 → 若者研究者減少 → 技術停滞）。

## 47〜48. 感情曲線と「何を捨てるか」

最も重要な感情曲線は「俺天才」→「そうなるの！？」のループ（問題発生 → 法則を書き換える → 問題解決 →「完璧に解決した」→ 時間を進める → 予想外の問題発生 →「そこに影響するのか！」→ 再び書き換える）。世界容量が圧迫されたら概念そのものを削除する（芸術・軍事・ペット・宗教・スポーツ）。「生存に必要ない」ものを削除すると、幸福・創造性・教育・科学・社会安定へ思わぬ影響が出る。

## 49〜51. リザルト・SNS共有・ランキング

終了後は数字だけでなく、作った世界そのものを見せる（WORLD 0234「空を飛ぶ不老文明」、♥不老社会 ✈自力飛行文明 ☮長期平和…、存在しないもの：海・戦争・国家・老化・肉食・睡眠、文明存続 1284年）。結果はカードとして共有でき、他プレイヤーと結果が大きく異なることを狙う。ランキングはカテゴリ別（⌛最長文明 ◆最小世界容量 ♥人類存続 ☮最長平和 🌿生態系維持 ★最高文明 ?最も奇妙な世界）。

## 52〜54. MVP

初期MVP：世界定義 約50、概念 約30、主要状態 約10、イベント 約100、ステージ 3（🍞食料 ✚疫病 ☀気候）。MVP用概念：人間・動物・植物・水・酸素・二酸化炭素・太陽・食料・火・温度・病気・免疫・老化・死・出生・睡眠・エネルギー・石油・電気・農業・工業・医療・教育・国家・貨幣・戦争・犯罪・科学・幸福・環境。

初回プレイ例：MISSION「30年間、人類文明を維持せよ。」開始時 🍞食料 不足 ⇊、💧水 不足 ↘。原因（人口増加・農地不足・水不足）を確認し、「人間は毎日食事を必要とする」を「人間は数日に一度食事を必要とする」に変更 → 数年後 🍞食料 十分 ↗ → さらに進めると ⚙食品産業 縮小、⚖雇用 悪化、⚗農業研究 停滞 → !新種病原体発生 → 🌾農業 危機 → 🍞食料 再び不足。

## 55〜61. 方針

情報の優先順位：第1階層（アイコン・状態語・方向）→ 第2階層（メーター・短い原因説明）→ 第3階層（因果関係・世界史・詳細分析）→ 第4階層（内部数値・統計）。「数字を見て最適解を計算するゲーム」にはせず、世界の兆候を読む → 原因を予想する → 世界法則を変更する → 結果を見る → 新しい仮説を立てる、という「世界を実験するゲーム」にする。完璧な世界は存在しない。同じミッションから全く異なる世界が生まれる。

キャッチコピー：「世界は、文章でできている。」「不要なものを、世界から削除してください。」「あなたなら、何を世界に残しますか？」「世界を救うために、世界を壊せ。」「世界のルールを書き換えろ。」

仮タイトル候補：WORLD.txt／世界再定義／世界容量不足／DEFINE／RE:WORLD／世界を編集する／世界から削除しますか？／WORLD ERROR／世界を書き換える。

最終的には、数字を管理するゲームではなく、世界を観察し、仮説を立て、世界そのものを書き換えるゲームとして完成させる。

## 試作で変えたこと（ユーザーの指示）

- **選択肢と予測をなくした**：「選択や予測はない方が良い」「好き勝手消したり書き換えたり付け加えたりできた方が良い」という指示で、構造化編集と影響予測（15〜16章・43章）をやめ、最初から自由な文章で書き換える形にした。結果は時間を進めて初めてわかる
- **現実に沿わせた**：「結構リアルにして」「現実ではこうなるだろうのような」という指示で、因果と数値を現実の仕組みに合わせ、想定外の変化に「なぜ？」を添えた
- **見た目**：ユーザーのタイトル画面の例に合わせ、黒と銀の写本・ゴシック調にした。BGM（The Unfolded Manuscript）と共有用画像（OGP）もユーザー提供
- **深めた**：「より深めて面白くして」という指示で、次を足した
  - 想定外の変化に「← どの一文から来たか」を添え、「そこに影響するのか！」を見えるようにした（47章の感情曲線）
  - 観測記録：見つけた読み取り・想定外の変化・出来事・結末が世界をまたいで集まる（37章の概念収集に近いもの）
  - 書き足した文章が既存の行と同じものについての文なら、その行の書き換えとして読む。短く言い換えれば意味を保ったまま軽くなる（6章の世界容量）
  - 辻褄の合う組み合わせ（季節がない＋気温が変わらない など）は、世界の揺らぎを戻す（39章のシナジー）
  - キャンペーン（35章）から STAGE 4 世界大戦・STAGE 5 資源枯渇・STAGE 6 極小世界を足した（極小世界は「何を捨てるか」の章をそのまま遊べる形）
  - リザルトに人口と文明の曲線・この世界の歩み・共有画像（50章の SNS 共有）を足した
