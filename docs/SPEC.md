# ラプラスの庭（WORLD.txt）仕様

## 1. 概要と、作った範囲

世界を定義している文章（WORLD.txt）を**自由に消す・書き換える・書き足す**ことで、人類文明を存続させるテキストベースの世界シミュレーション。スマホ縦画面のブラウザゲーム。題名の「ラプラス」は、世界のいまの状態と決まりをすべて知れば未来が決まる、という考え（ラプラスの悪魔）から。

- **乱数を使わない世界（ラプラスの決まり）**：世界の初期条件と出来事の起きる時期は、世界番号（#0001〜#9999）から決まる式だけで決まる。遊んでいる間はさいころを振らない。同じ世界番号・同じ書き方なら、誰が遊んでも同じ世界になる。書いた手の並び（棋譜）から、同じ世界をいつでも作り直せる
- プレイヤーが触れるのは文章だけ。選択肢も、書き換えの結果の予測も出さない。結果は時間を進めて世界を見るまでわからない
- 書いた文章は、世界が語彙から意味を読み取る（否定・量・頻度・例外・条件・「〜なしで」・「〜だけ」・「〜に強い」・英語・書き方の読み分け）。**どんな文でも受け取る**：その行の新しい意味／新しい概念（1文にいくつでも）／別の行の書き換え／すでにある意味（重複）／意味のない文（理由つき）のどれかになる。**意味のない文では、世界は何も変わらない**（書換の力も使わない）
- **兆しを読んで見立てる**：同じステージでも、世界番号ごとに危機の原因の型（食料危機なら水が足りない・届かない・病害）が違う。はじめの2年のニュースに型の兆しが出る。型に合った仕組みを書き足さないと、数年後に「壁」の出来事がくり返し、大崩れが来る
- 因果は現実の仕組みに沿わせる。想定外の変化には「なぜ？」を一文で添え、**どの一文から来たか**を示す。現実の数字には出典を付ける（docs/SOURCES.md）
- 世界の中の人々の心（信頼・先行きの不安・慣れ・損の重さ・考え方の広がり など）と、社会の学問の決まり（遅れ・行きすぎ・転換点の前ぶれ など）が動いている。学問の仕組み25は、**開いていく順番**で1つずつ紹介し、紹介する前は弱く動かす
- 世界を救うと**筆の位**が上がり、書き換えられる範囲が広がる。世界ごとに**3つの印**（救った・少ない手で・早く見抜いた）、4種類の**実績**、**図鑑**、全部救ったあとの**改稿者の試練**
- **無限の世界**（文明が滅ぶまで続き、危機が来る）と、**くり返す十年**（10年ごとに0年目へ巻き戻る）、はじめの**序章「ひと区画の庭」**（5行だけの小さな世界で、書き換える・書き足す・消すを1年に1つずつ。手引きが押す順に示す）
- 暗い画面（黒と銀）と明るい画面（紙と墨）。最初は端末の設定に合わせる

## 3. ルール

### 3.1 世界の中身（1年ごと）

内部の状態（人口・農業・産業・発電・再エネの割合・石油の残り・物流・科学・生態系・CO2・気温・流行・免疫・病原体の強さ・作物の病気・食料の蓄え・社会の安定・幸福・国際緊張・戦争・失業・心・物価・世界整合性・世界容量、人々の心：慣れた水準・これまでの高み・信頼・先行きの不安・用心・行きすぎ）を、毎年つぎの順で進める。

1. 法則（読み取った意味）・行が運ぶ意味・組み合わせ・副作用・一時的な出来事から「係数」を組み立てる。書いた行の意味は、**言い切りの強さ**（強い1.3・ふつう1・控えめ0.6）、**効き始めまでの遅れ**（建てる・育てるものほど遅い：農業・植物1年、CO2・海・環境・教育2年、ため池1年、海水の淡水化2年、植林3年、原子力発電3年 など）、**世界の適応**（書いてから8年たつと効きが落ち始め、さらに10年で本来の7割まで。変わらない物の理は落ちない）、**読まれ方**（3.6）を掛けて効く
2. 食料・水・エネルギーの釣り合い → 農業と発電の伸び縮み → 病気・人口・産業・物流・科学・CO2と気温・生態系・社会・国際緊張・戦争・心・物価・世界整合性
3. 人々の心と社会の学問の決まり（3.7）
4. 遅れて効く副作用が育つ → 組み合わせの成立 → 出来事（型の兆しと壁を含む。起きる力がたまった年に起きる。3.5）→ 世界異常 → 危機（無限の世界）
5. 書換の力が戻る → 終わりの条件 → 人口・文明・慣れの曲線を記録する

書き換えただけでは世界の様子は計算し直さない（結果は時間を進めて初めてわかる）。世界容量と整合性の元になる重さだけは、すぐ変わる。

### 3.2 書き換え（命令）

| 命令 | 内容 | 書換の力 |
|---|---|---|
| 行を書き換える | 既存の法則の文章を好きに書き換える。読み取った意味に切り替わる。同じ文に書いた新しい概念も、その行が運ぶ。別のものについての文に書き換えると、元の定義は消え、新しい意味がその行に宿る | 1 |
| 行を消す | 文章を空にする。その法則の「削除したときの意味」になる。**空白の行**は5年たつと世界が元の文で埋める（その行の意味が戻る）。消した行は**消し跡**として元の字数の半分を使い続ける。支えていた行を消すと、支えられていた行の整合性が下がる | 1 |
| 書き足す | 新しい一文を足す。言い回し集 → 既存の行の書き換え → あとで読む言い回し → 種類ごとの読み取り の順に読む。既存の行の話なら、その行の書き換えとして読む（すでに書き換えた行なら重ね書き） | 1 |

- **書換の力**：はじめ2、7年ごとに1戻る（最大4）。極小世界ははじめ3・4年ごとに1（最大5）。序章は毎年1。くり返す十年は巻き戻るたびに1戻る
- **世界容量＝使える文字数**：行の重さは文字数と、行が運ぶ新しい概念の重さの合計。初めの WORLD.txt は579字。ステージごとに毎年少しずつ縮む（3.9 の表）。同じ意味のまま短く言い換えれば字数を減らせる（1行につき1度まで）
- 同じ行を2度目から書き直すたびに**上書きの傷**で整合性が少し下がる
- 筆の位（3.13）で書けないものは止める（書換の力も世界容量も使わない）
- 同じ意味の定義は重ねられない。意味のない文は書けない（書く前に知らせる）

### 3.3 読み取り（`src/core/interpret.ts`）

形態素解析はせず、文章から手がかりを取り出して、法則ごとの規則（`laws.json` の `match`）と言い回し集（`phrases.json`）に当てはめる。英語と言い換えは、読む前に日本語の言葉へそろえる（`lexicon.json`）。同じ文章からは、いつも同じ読み取りになる。

| 手がかり | 例 |
|---|---|
| 否定 | 〜ない・〜しない・不要・消える・存在しない（「少ない」「〜しなければならない」は否定にしない） |
| なくなることの打ち消し・二重否定・場所を限った否定 | 「終わらない」は「続く」／「Xなしでは〜ない」は元の意味／「作物は海では育たない」はそのほか元のまま |
| 量・頻度 | 少し・倍・大量／数日に一度・週に一度・時々 |
| ないもの・それだけ・強さ | 「Xなしで」「Xだけ」「〜に強い」「〜に弱い」 |
| 例外・条件 | ただし〜・〜を除く／〜のとき・〜なら |
| **言い切りの強さ** | 強い（必ず・絶対に・すべて）・控えめ（〜かもしれない・少しは・ときには） |
| **読まれ方**（人の振る舞いの文） | 性質（「人は〜する」）・制度（〜しなければならない・〜が決める・〜が定める）・条件つき（〜のときだけ・足りない年は） |
| 何についての文か | 行ごとの主語（`subject`）と話題の言葉（`topic`） |

- 言葉は「その言葉として」数える（「人工知能」の「人」は数えない）。主語が別のものの文、新しいものを持ち込んだ文、その行の知らない動きの文は、その行の意味にしない
- 意味のない文には理由を返す（記号だけ／短すぎる／問いかけ／知らない言語／知らない言葉／意味がつかめない）
- 日常の言葉の種類（18種・1114語）と語尾から種類を推し量る。種類ごとの読み取り（「{X}がいなくなる」など23）は、ほかに何も読めなかったときだけ
- 回帰テスト：`tests/wild.test.ts`・`tests/interpret.test.ts`・`tests/modes.test.ts`。総当たり：`npm run fuzz`（約2万文。5章）

### 3.4 原因と観測記録

- 副作用・出来事・世界異常・危機のニュースには、それを育てた行・条件に書かれた行を「原因」として付ける（プレイヤーが書き換えていない行は原因にしない）。敗因の振り返りと因果の連鎖は、この原因だけでつなぐ
- 観測記録の id：`r:法則.読み取り`／`p:言い回し`／`t:副作用`／`e:出来事`／`k:危機`／`c:組み合わせ`／`a:世界異常`／`g:世界の名前`／`end:ステージ.結末`／`x:特別な結末`／`h:初めて起きたこと`（買いだめ・広がり・戻りの遅さ・知らない言葉・因果の地図・柱の不安・読み分け・負け・3回目の負け・もう一度・番号で開く・空白に書く）／`m:使った読まれ方`

### 3.5 乱数を使わない世界（ラプラスの決まり。`src/core/hash.ts`）

- 世界番号から決まる式（`hash01`）で、はじめの状態のずれ・原因の型・出来事ごとの「起きる力」のはじめのたまり具合を決める。起きる力のはじめの値は `1 + ln(1 − u)`（u は世界番号と出来事の名前から決まる0〜1）で、毎年、起きやすさの分だけたまり、1に届いた年に起きる（昔の「毎年さいころを振る」やり方と同じ待ち時間の分かれ方になる）
- 戦争が始まるかは、国際緊張のばらつきを正規分布とみて、加わる人の割合が半分を超えるかで決める（閾値のなだれ）
- 遊んでいる間はさいころを振らない。同じ世界番号・同じ書き方なら同じ世界。今日の世界の世界番号は日付から作る。くり返す十年は、巻き戻るときに起きる力も0年目に戻す
- 棋譜：世界番号・ステージ・原因の型・筆の位・決まりの強さ・規則の版（データの中身から作る）と、手の並び（何年目・何周目・どの行・消す／書き換える／書き足す・書いた文・読まれ方）。棋譜から世界を作り直す関数 `replayKifu`（3.15）

### 3.7 人々の心と社会の学問（`src/core/people.ts`・`balance.json` の `people`）

- **慣れと損の重さ**：人は今の暮らし（食料・水・エネルギー・失業の対数）と、慣れた水準との差で満足する。慣れた水準は年2割ずつ今に近づく。下がった分は1.6倍に重く感じる
- **上げてから落とす（J字）**：これまでの高みから急に落ちると、不満と国際緊張が大きくなる。物価の上がる速さも緊張を上げる
- **信頼**：安定した年にゆっくり上がり、不足・闇市・世界の揺らぎ・戦争で速く下がる。制度として書いた決まりは、信頼が低いと形だけ守られる（最低5割）
- **先行きの不安と買いだめ**：不足・物価・蓄えの少なさ・信頼の低さで不安が上がり、不安62以上かつ信頼40未満で買いだめが起き、物の流れが細る（予言の自己成就）
- **用心の波**：感染が広がると人は接触を減らし、落ち着くと緩める。流行は波になる
- **限りを超えた崩れ**：生態系と水が限りを割った状態が続くと、ふだんなら耐えられる出来事で大きく崩れる
- **戻りの遅さ**：文明が終わりの線に近づくと、揺れからの戻りが遅くなる（転換点の前ぶれ）
- **乏しさ・人口転換・豊かさと満足**：足りない年は研究が鈍る。教育と医療が良くなると生まれる子が減る。満足は豊かさの対数で上がる
- **考え方の広がり**：性質として書いた考え方は、人から人へ広がった分だけ効く（S字。25%を超えると一気に広がる）。同じことを決まりでも書くと、心からの振る舞いが締め出され、決まりを消しても戻らない。罰の仕組みがないと、心からの分け合いはただ乗りで薄れる
- **読まれ方**：性質（広がった分だけ効く）・制度（国家の行が要り、信頼で効き方が変わる。長引くと闇市と疲れ）・条件つき（条件を満たした年だけ0.6倍）

### 3.8 開いていく順番（`src/data/unlocks.json`・`src/core/unlocks.ts`）

1回のプレイで新しく覚える考えは1つ。体験してから名前と画面が開く。開く条件は救った世界の数・遊び終えた世界・世界で初めて起きたことだけで、運では開かない。開いたものは閉じない。

| 開く時期 | ステージ | 筆の位 | 1つの考え／出会う決まり |
|---|---|---|---|
| はじめ | 序章 ひと区画の庭（5行・3年。何もしなくても救える） | 見習い | 書いてから効くまで／遅れ |
| 序章のあと | 食料危機 | 見習い | 兆しを読んで見立てる／先行きの不安と買いだめ・乏しさ |
| 食料危機を遊び終えた | 感染症・気候危機 | 見習い | 世界は慣れて変わる／用心の波・助け合いと疲れ、狭まる余裕と転換点／転換点と戻りの遅さ |
| 1つ救う | 世界大戦・資源枯渇・無限の世界 | 写字生 | つながりの連鎖・重なる危機と予備・人は比べて感じる |
| 2つ救う | くり返す十年 | 書記 | 小さな違いが育つ |
| 2つ救い、社会の文が初めて制度か条件つきとして読まれた | （どの世界でも） | 書記 | 書き方と人の心／信頼・考え方の広がり・締め出し・ただ乗り |
| 3つ救う | 極小世界 | 改稿者 | からみ合い／三つのからみ・柱の重さ・どこかが減る |
| 5つ救う | すべて | 創世 | 長い年月の決まり。すべての決まりが本来の強さで動く |

**序章の手引き**（`stages.json` の `tutorial`・`src/ui/Coach.tsx`）：年ごとに1つの操作を、押す順の手順で示す。1年目「書き換える」（法則を開く → 「虫や鳥が花粉を運ぶ。」の行 → 「虫や鳥がたくさんの花粉を運ぶ。」と書き換える → 1年進める）、2年目「書き足す」（「行を書き足す」→「人々は食べ物を分け合う。」→ 1年進める）、3年目「消す」（「食べ物は時間がたつと腐る。」の行 → 文章を消して「この行を世界から消す」→ 1年進める）。済んだ手順には印をつけ、いまの手順を濃く出し、押す物（法則のタブ・その行・行を書き足す・世界を書き換える・1年進める）に枠をつけて3回だけ光らせる。手本は、はじめての筆で書けて次の年に知らせと情景に表れる（花畑に蜂と鳥・市場の分け合う棚・蔵に積み上がる食べ物。`tests/prologue.test.ts` が世界番号5つで確かめる）。手本どおりでなくても、その年の操作をすれば手順は進む

- **紹介する前の強さ**：学問の仕組みは最初から全部動いているが、紹介する前は本来の3割（`balance.intro.before`）。紹介した世界で、年2割ずつ本来の強さへ上がる。わかった決まりは次の世界から本来の強さ
- **わかった世界の決まり**：紹介する段が開いていて、その段の世界を遊び終えた（ステージのない段は開いたとき）か、その決まりの「初めて起きたこと」を見た
- **発見で開くもの**：知らない言葉を書いた → 世界の辞書、因果の線が想定外の所に届いた → 因果の地図、柱が初めて「不安」になった → 柱の中身、初めて負けた → 敗因の振り返り、同じ世界で3回負けた → 兆しの読み方（3回ごとに1つ）、広がりが25%を超えた、戻りが遅くなった、同じ世界でもう一度 など
- すべてを一度開いたら、メニューに「すべて開いた状態で始める」
- 古いセーブ（版5まで）は、記録の残っている世界と序章を遊び終えたことにして読む（これまでの世界が開いたまま）

### 3.9 世界ごとの3つの印・作り手の解・改稿者の試練（`src/core/marks.ts`）

| 印 | 条件 |
|---|---|
| 救った | 最後の年まで、どの線も割らない |
| 少ない手で | 救い、手の数（書き換え・書き足し・消すの合計）が作り手の解の手数以内（`stages.json` の `causes[].par`） |
| 早く見抜いた | 分かれ道の年（原因の壁の兆しが最初に出た年）より前に、原因に効く手を打った |

- 印はステージごとに、これまでに付いたものを残す。分かれ道からやり直した世界には「少ない手で」「早く見抜いた」は付かない。序章と無限の世界には印を付けない
- **作り手の解**：型ごとの手（`scripts/strategies.ts` の READERS）。手数は、その手順が救えた世界での手の数の最大：食料6・感染症7・気候8〜9・大戦7・資源6〜7・極小14・くり返す十年7
- **改稿者の試練**：その世界の3つの印をそろえると開く難しい版。原因の型が2つ重なる（食料・大戦）／兆しが1年遅れて出る（感染症・資源・極小）／書き換えが少ない（気候・くり返す十年。はじめ2・10年ごとに1・最大2）。救うと実績「改稿者の試練」

### 3.10 実績（`achievements.json`）と図鑑

- 4種類：**発見**（最初の一文・世界の綻び・観測者・見立てが当たった・三つの読まれ方・世界の決まりを知る者 など15）、**腕前**（一文で救う・七つの世界を救った者・三つの印・消さずに救う・決まりに頼らずに・棚の空かない世界・空白に書く など20）、**物語**（特別な結末ごとの隠し実績 など24）、**遊び方**（今日の世界・半世紀・神の筆（無限の世界で15回書き換えた）・番号の世界・改稿者の試練 など10）
- 負けや放棄で取れる2つ（早すぎる終わり・もう一度はじめから）は隠しのおまけにして、達成の数に入れない
- 取ったときは、名前と何がうまかったかの1行を知らせる
- 図鑑：世界の決まり25・現実のカード77（決まりのカード25＋書き換えた行の「現実では」52）・特別な結末41・世界の名前123。隠し実績は種類ごとに数と手がかりを1つ
- 入れないもの：連続ログインのボーナス、期間限定、くじ、遊びが有利になるごほうび

### 3.11 終わり・無限の世界・特別な結末

- CLEAR：目標年数に到達、または特別な結末（クリア）。失敗：人口がステージの下限を下回る／文明の点数25未満が3年続く／世界整合性の崩壊／使える文字数の超過が3年続く、または特別な結末（ゲームオーバー）
- **無限の世界**：危機10種（巨大隕石・未知の病・破局噴火・太陽嵐・大干ばつ・寒い時代・作物の疫病・世界大戦・世界恐慌・巨大地震）。知らせから数年後に襲い、世界の定義しだいで防げる・弱まる。危機の知らせで、その危機を防ぐ行のロックが襲うまで解ける。記録簿（上位10件）と称号
- **特別な結末**41（無・ほどけた物質・崩れる原子核・のまれた星・永遠の一瞬・星々の友・星々への旅立ち・閉じた永遠・楽園 など。滅び方の名前：核の冬・凍りついた星・紙くずの星・心の尽きた星 など）
- **くり返す十年**：その10年のうちに大戦が起きるか文明が保たれないと、10年目の終わりに0年目へ戻る。巻き戻るたびに使える文字数が30字減り、書換の力が1戻る。凍土の病 → 不作 → 食料をめぐる戦争の連鎖を断って11年目へ抜け、30年を生き延びれば CLEAR
- 開ける世界は1つだけ。別の画面で同じセーブが書き換えられたら、古い画面は保存をやめる

### 3.12 書き換えた年の世界・世界の情景

- 書いた一文は、効き始めた年に「世界が書き換わった」と知らせ（`onset`）、情景にそのとおりに描く（書いただけでは見せない）。書き換えの勢い（`balance.impulse`）で、ゆっくり動く量がその年のうちに動く
- **世界の情景**（`src/store/scene.ts`・`src/ui/scene/`）：状態（町の灯り・塔・遠近法の畑と鍬をふるう人・森・川・海・煙・霧・戦火 など）と書き換えのすべてを描く（描く要素191）。書き換えから来たものは青いインク。施設は見分けのつく形にする：蔵はサイロ、工場はのこぎり屋根と煙突（動いていれば明かり取りが灯る）、病院は窓の多い2階建てと屋上の白い十字、港は岸壁と杭とクレーン（物流が盛んなら荷を吊る）、町のはずれの貯水池と川は水位（水が減ると水面が縮んで下がり、乾いた岸と水位の跡が現れる。ため池・ダムを書くと堤ができて水位が上がる）。作物の病気が広がると、株の先に病斑が出る。消した行があると、畑のはずれに縁を書いたインクで囲った空き地ができ、世界が埋める年が近づくほど草が伸びる。光は左から来る（塔・病院・サイロの右の面に影）。遠い山のふもとは空の色にかすみ（空気遠近法）、遠い船ほど小さい。人は頭が全身の約4分の1の形で、立つ・歩く・バケツを持つ・鍬をふるうを描き分ける。水が足りないと給水の列（バケツを持った人と給水の塔）。**施設の名前**（畑・貯水池・森・町・病院・工場・港。気がかりな状態の言葉つき。作物の病気が広がると畑は「病気」。水が足りないときは「給水の列」、消した行があるときは「消した行」も出す。10px 以上・背景つき。切り替えられる）。起きかけていることのカードを押すと、絵の同じ場所の名前が3回光る。情景は**飛び出す絵本**：空・遠景・中景・近景・手前の5枚の層を同じ大きさで重ね、層ごとに切り絵の影を落とす。世界を開いたときに一度だけ、奥の層から順に起き上がる（約1.2秒。動きを減らす設定では起き上がらない）。知らせや結果の小さな窓の情景は1枚の絵のまま
- 時間を進めた年は、去年の絵をインクの縁が塗り替え、新しく現れたものはそのものらしく現れ、なくなったものは消えていく。飾りの動きは、年が進んだときに1回だけ（約1.2秒）で、見せ終えたら止まる。世界異常のときはゆがみと色のずれ（feDisplacementMap）、大崩れのときは色が落ちる。時間が止まった世界・逆に流れる世界（書いた文・世界異常・結末）では、ずっと続く動き（雲・煙・人・船など）を止める・逆に流す。その年に現れる・消える1度だけの動きには当てない（止めると現れないまま、逆にすると現れてから消えてしまうため。e2e で確かめる）

### 3.14 世界の寿命・4つの柱・起きかけていること（`src/store/view.ts`）

- **世界の寿命**：人口・文明・世界整合性・使える文字数の4つの終わりの線のうち、いちばん近い線（線を越えていれば終わるまでの年、近づいていれば去年の動きが続いたら届く年のいちばん短いもの）。「あと約◯年」と棒1本。近づいていなければ近さの言葉。書き換えの結果の予測ではなく、去年の動きをのばしただけ
- **4つの柱**（`indicators.json` の `pillars`）：命（人類・健康・心）・糧（食料・水・エネルギー）・社会（社会・世界情勢・科学・物流・産業・物価）・大地（生態系・気候）。柱には、いちばん低い項目と状態の言葉。棒は4本とも同じ位置（左から2割）に終わりの線
- **起きかけていること**（`src/core/signs.ts`）：知らされた危機・戦争の前ぶれ・起きる力のたまった出来事・育ち始めた副作用・人々の揺れ。急ぐものから3枚まで

### 3.15 棋譜・再生・分かれ道・敗因の振り返り

- **棋譜**（`src/core/kifu.ts`）：世界ごとに残し、ステージごとにいちばん良かった棋譜（救った中で手の少ないもの。救っていなければ長く続いたもの）を `progress.kifu` に残す。規則の版が違う棋譜は再生せず「今の規則では再生できない」と出す（記録は消さない）
- **再生**：結末で、棋譜から世界を作り直し、1年ずつ（自動で約10秒、押すと止まる）その年の情景・書いた手・大きな出来事を見返す
- **分かれ道からやり直す**：終わった世界の棋譜を、分かれ道の年（その年の手は書かない）まで作り直し、そこから遊ぶ。印の「少ない手で」「早く見抜いた」は付かず、いちばん良かった棋譜にも残さない
- **敗因の振り返り**（`src/core/review.ts`）：負けた世界で、崩れた年と割った線 → 崩れる前の注意・重大な出来事（新しい順に3つ）→ 分かれ道（その年に見えていた兆しだけ）→ それらに原因として付いていた書いた一文。後知恵で責めない

## 7. 操作

- タップ：押せる物は44px以上
- 文字入力：書く画面の編集欄（最大80字）。入力の補助はカーソルの位置に差し込むだけ（選択肢や結果の予測ではない）
- 時間：「1年進める」だけ（1回で1年）。計算の演出はタップで飛ばせる。結果の画面の「次の1年」で続けて進める。何も起きなかった年は結果の画面を出さずに世界へ戻る
- 取り返しのつかない操作（セーブの上書き・この世界をあきらめる・別の世界を開く）は2度押し
- 長押し・右クリックで、文字の選択・コピーなどのメニューを出さない（編集欄と読み込み欄は除く）

## 10. 安全（セキュリティ）

- **読み込めるものを絞る決まり（CSP）**：公開用のビルドの index.html に meta で入れる（`vite.config.ts`）。スクリプト・通信はこのサイトだけ、書体は Google Fonts だけ、画像は自分・data・blob だけ。e2e で、遊んで結果の画像を保存するまでに CSP に触れないことを確かめる
- **文字列からコードを作らない**：eval・new Function を使わない。Zod は jitless
- **書いた文章は文字として出す**（innerHTML を使わない）
- **よそへ住所を伝えない**：`<meta name="referrer" content="no-referrer">`
- **読み込むセーブを疑う**：大きさ・文の長さ・数に上限、Zod で形を確かめ、`__proto__` などの鍵を取り除く。ファイルからの読み込みも同じ道を通る（400万バイトを超えるファイルは読まない）
- **テスト用の窓口**（`?debug=1`）は、開発中とテスト用のビルドだけ
- **公開の仕組み**：GitHub Actions は必要な権限だけ。依存の既知の弱点は `npm audit` で確かめる
