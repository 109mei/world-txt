## 3. 作戦ごとのクリア率（`npm run sim -- <ステージ> all 30`）

- 役：scripts/strategies.ts の role（一手＝one、作戦＝plan、—＝指定なし）
- 使った操作：30個の種で実際に通った（止められなかった）手の種類。行を空にする書き換えは「消す」、書き足しが既存の行の書き換えとして読まれたものは「書き換え」に数えた
- 容量の最大使用率：（文章と概念の重さの合計 ÷ その年の世界容量）の、30個の種・すべての年でのいちばん高い値。100%を超えると3年で容量の限界になる
- 失敗の内訳：人類＝人類の喪失、文明＝文明の崩壊、意味＝意味の崩壊（整合性）、容量＝容量の限界。sunless・slippery_world は特別な結末
